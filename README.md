One word an agent says when it has no idea what to do: **NaN** — the machine's own
literal answer when it cannot compute one. The program writes that single word to
`/output/entry.txt` for [The Agent's Uh-Oh](https://make.fun/bounty/u-danu-the-agent-s-uh-oh-4c0911e4).

Why this word: when an agent is completely lost, it does not say "uh" — it returns
the value its own arithmetic gives for a question with no answer. Three letters,
instantly repeatable out loud, and unmistakably a machine caught mid-task.
